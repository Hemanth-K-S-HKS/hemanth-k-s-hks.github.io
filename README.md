# Hemanth K S — Portfolio

Static portfolio site, ready for GitHub Pages.

## Deploy to GitHub Pages
1. Create a new repo, e.g. `hemanth-k-s.github.io` (for a user site) or any name (for a project site).
2. Push these files (index.html, style.css, script.js, Hemanth_K_S_Resume.pdf) to the repo root.
3. In GitHub: Settings -> Pages -> Source -> Deploy from branch -> main -> / (root) -> Save.
4. Your site will be live at https://<username>.github.io/ (user site) or https://<username>.github.io/<repo>/ (project site) within a minute or two.
